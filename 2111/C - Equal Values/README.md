The cost of such an operation is $$$(i - 1) \cdot a_i$$$. </li><li> Choose a position $$$i$$$ ($$$1 \le i  \lt  n$$$) and make all elements to the right of $$$i$$$ equal to $$$a_i$$$. That is, assign the value $$$a_i$$$ to all $$$a_j$$$ ($$$i  \lt  j \le n$$$).
